# personal-site

William Koonz — personal portfolio. Next.js (App Router) + TypeScript + Tailwind v4.

```bash
npm install
npm run dev   # http://localhost:3000
```

## Structure

- `src/app` — routes, layout, global styles
- `src/components` — UI components
- `src/lib` — utilities / content helpers
- `public` — static assets
